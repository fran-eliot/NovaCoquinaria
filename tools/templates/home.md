# Bienvenido a NovaCoquinaria

Una base de conocimiento culinario modular diseñada para aprender, reutilizar y evolucionar.

> **Más que un recetario: un Sistema de Gestión del Conocimiento Culinario.**

NovaCoquinaria organiza el conocimiento culinario como si fuera un proyecto de software.

Las técnicas, ingredientes, plantillas y recetas se documentan de forma modular para evitar duplicidades y facilitar su reutilización.

El resultado es una base de conocimiento preparada para crecer durante años y servir de fundamento para futuras aplicaciones.

## 🚀 Comenzar aquí

Si es tu primera visita, este es el recorrido recomendado:

1. 📖 Descubre la filosofía del proyecto.
2. 🍳 Aprende los fundamentos culinarios.
3. 🧂 Explora la despensa.
4. 🧩 Conoce las plantillas reutilizables.
5. 🍽️ Consulta las recetas.
