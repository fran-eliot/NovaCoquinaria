# Legumbres

## Objetivo

El módulo **Legumbres** reúne recetas de lentejas, garbanzos y alubias, conectadas con ingredientes, técnicas y plantillas reutilizables. Se diferencia entre legumbre seca y legumbre ya cocida para no confundir sus tiempos ni sus requisitos de preparación.

## Ruta práctica de aprendizaje

1. Revisar [Cocer legumbres secas](../00_Bases/03_Tecnicas/cocer_legumbres.md) y las diferencias entre especies.
2. Preparar [lentejas estofadas](./lentejas_estofadas_con_verduras.md) para practicar un guiso con cocción directa.
3. Preparar [garbanzos con espinacas](./garbanzos_con_espinacas.md) para trabajar con legumbre cocida.
4. Preparar [alubias blancas estofadas](./alubias_estofadas.md) para practicar remojo y cocción lenta.
5. Comparar [hummus](./hummus_de_garbanzos.md), [dhal](./dhal_de_lentejas_rojas.md) y [ensalada](./ensalada_de_lentejas.md) para practicar triturado, cocción cremosa y preparación fría.
6. Adaptar la [plantilla de guiso](../12_Plantillas/04_Cocciones/guiso_de_legumbres.md) a otras verduras y condimentos.

## Criterios del módulo

- Diferenciar siempre legumbre seca, remojada y cocida.
- Ajustar tiempos por variedad, antigüedad, método y textura buscada.
- Documentar precauciones específicas para alubias rojas secas.
- Priorizar referencias cruzadas antes que duplicar explicaciones.
- Mantener las recetas y sus variantes identificables y reproducibles.
- Registrar cantidades y tiempos como orientaciones verificables durante la cocción.
