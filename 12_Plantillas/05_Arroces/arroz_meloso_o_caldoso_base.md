# Plantilla: Arroz meloso o caldoso base

## Objetivo

Construir arroces de cuchara diferenciando un caldo ligado y un caldo libre, sin convertir el método en una receta única. Es una **estructura culinaria reutilizable**, no una receta concreta ni una formulación doméstica verificada.

## Proporciones iniciales

Referencia para **3 raciones**. Adaptar estas cantidades a la receta, el producto y el recipiente.

| Elemento | Cantidad orientativa | Función |
|---|---|---|
| Arroz redondo adecuado | 240 g | cereal |
| Base aromática y verduras | 200–300 g | sabor |
| Aceite | 2 cucharadas | sofrito |
| Caldo caliente para meloso | 750–950 ml orientativos | líquido ligado |
| Caldo caliente para caldoso | 1–1,2 l orientativos | caldo abundante |
| Proteína opcional | según ingrediente | aporte principal |

## Patrón de elaboración

1. Preparar sofrito y concentrar la humedad antes de incorporar el caldo.
2. Elegir textura de destino: melosa con caldo ligado o caldosa con líquido abundante; no son el mismo resultado.
3. Añadir arroz y caldo caliente de forma gradual o en el volumen previsto según receta, manteniendo hervor suave.
4. Incorporar proteínas delicadas cerca del final, teniendo en cuenta su necesidad de cocción completa.
5. Verificar grano y textura antes de apagar; servir inmediatamente, pues el arroz sigue absorbiendo líquido.

## Decisiones para adaptar el patrón

- Para meloso: buscar movimiento fluido y ligado, sin pasta apelmazada.
- Para caldoso: reservar caldo caliente para ajustar al momento de servir.
- Para pescado o marisco: añadir cerca del final y comprobar cocción.

## Diagnóstico

- Meloso seco: evaporación excesiva o reposo prolongado.
- Caldoso espeso: demora en el servicio o cantidad insuficiente de fondo.
- Arroz duro: líquido frío añadido repetidamente o cocción incompleta.

## Seguridad y conservación

Servir enseguida; enfriar rápidamente las sobras y conservarlas refrigeradas. Cocinar por completo las proteínas incorporadas.
