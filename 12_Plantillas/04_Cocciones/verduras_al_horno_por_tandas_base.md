# Plantilla: Verduras al horno por tandas base

## Objetivo

Coordinar hortalizas con densidades distintas para lograr dorado y ternura sin que unas se deshagan mientras otras siguen crudas. Es una **estructura culinaria reutilizable**, no una receta concreta ni una formulación doméstica verificada.

## Proporciones iniciales

Referencia para **4 raciones**. Adaptar estas cantidades a la receta, el producto y el recipiente.

| Elemento | Cantidad orientativa | Función |
|---|---|---|
| Verduras densas: patata, zanahoria, calabaza | 400–500 g | primera tanda |
| Verduras medias: pimiento, cebolla | 250–350 g | segunda tanda |
| Verduras tiernas: calabacín, champiñón | 200–300 g | última tanda |
| Aceite de oliva | 2–3 cucharadas | recubrimiento ligero |
| Sal y hierbas | según elección | aroma |

## Patrón de elaboración

1. Precalentar horno a 200–210 °C y preparar bandeja amplia, evitando amontonar.
2. Lavar y secar las hortalizas; cortar las densas más pequeñas y las tiernas algo mayores.
3. Comenzar con las verduras de mayor tiempo, removiendo al cabo de 12–15 minutos.
4. Añadir sucesivamente los grupos más tiernos, dejando espacio entre piezas para que salga el vapor.
5. Verificar dorado y ternura de cada grupo; retirar una verdura ya hecha si las demás necesitan tiempo.
6. Sazonar hierbas delicadas al terminar para no quemarlas.

## Decisiones para adaptar el patrón

- Si la bandeja está llena, dividir en dos tandas o usar dos fuentes.
- Si se busca dorado, secar superficies y evitar exceso de líquido.
- Si se pretende textura suave, usar temperatura más moderada y una parte de cocción tapada.

## Diagnóstico

- Verdura cocida al vapor: bandeja saturada.
- Patata dura: corte demasiado grande o incorporación tardía.
- Hierbas amargas: se quemaron desde el inicio.

## Seguridad y conservación

Lavar adecuadamente las hortalizas; enfriar sin demora las sobras cocinadas y conservarlas refrigeradas.
