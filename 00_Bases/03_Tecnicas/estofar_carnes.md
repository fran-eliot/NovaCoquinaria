# Estofar carnes

## Objetivo

Transformar cortes con tejido conectivo mediante cocción prolongada, humedad y calor moderado. La técnica combina dorado opcional, base aromática y hervor muy suave.

## Selección del corte

| Corte o característica | Adecuación |
|---|---|
| Ternera para guisar, morcillo, aguja | Adecuado para cocción prolongada |
| Paleta de cerdo | Adecuada por tejido conectivo y grasa |
| Lomo magro en filetes | Menos adecuado para estofados largos |
| Pechuga de pollo | Puede resecarse en cocción prolongada |

## Secuencia de trabajo

1. Preparar verduras y utensilios limpios. Mantener la carne cruda separada.
2. Cortar la carne en dados de tamaño semejante y secar superficialmente.
3. Dorar por tandas si se busca mayor complejidad de sabor; reservar en recipiente para carne parcialmente cocinada.
4. Pochar cebolla y otras verduras; desglasar con líquido si el fondo presenta residuos dorados no quemados.
5. Añadir tomate o especias según la preparación.
6. Devolver carne y jugos; incorporar caldo hasta cubrir parcialmente.
7. Cocinar tapado o semitapado a **hervor suave**, ajustando el líquido.
8. Comprobar cocción segura y **terneza real**: un corte con colágeno puede requerir más tiempo aunque ya haya alcanzado temperatura de seguridad.
9. Reducir la salsa destapada al final, si procede.

## Variables

| Variable | Consecuencia |
|---|---|
| Corte | Determina tiempo y textura final |
| Tamaño de dados | Modifica uniformidad |
| Intensidad del hervor | Exceso puede resecar o endurecer fibras |
| Cantidad de líquido | Determina concentración |
| Tapa | Controla evaporación |
| Tiempo | Permite transformación del tejido conectivo |

## Diagnóstico

| Problema | Causa probable | Corrección |
|---|---|---|
| Carne dura | Tejido conectivo aún sin ablandar | Prolongar cocción suave |
| Carne seca | Corte magro o exceso de calor | Cambiar corte o moderar |
| Salsa acuosa | Mucho líquido | Reducir al final |
| Fondo quemado | Evaporación y calor alto | Bajar fuego y vigilar |
| Verduras deshechas | Incorporación demasiado temprana | Escalonar |

## Seguridad

No usar un tiempo fijo como prueba de seguridad. Evitar contaminación cruzada y mantener una cocción suficiente para el producto. Enfriar rápidamente en recipientes poco profundos y refrigerar las sobras.

## Principio de NovaCoquinaria

> La terneza de un estofado depende del corte y de una cocción suave sostenida, no de hervir con fuerza.
