# Cortar carnes según la fibra y la cocción

## Objetivo

Adaptar el sentido y grosor del corte de carne al método de cocción para mejorar la percepción de ternura, la regularidad del punto y la manipulación segura.

## Cuándo aplicarlo

- Tiras de ternera para saltear.
- Medallones de solomillo para sellar.
- Dados de carne destinados a estofado prolongado.

## Principios

| Elemento | Criterio |
|---|---|
| Dirección de la fibra | Cortar perpendicularmente a las fibras acorta los haces musculares y facilita la masticación. |
| Grosor | Las tiras finas se cocinan antes que piezas gruesas; las piezas para estofado deben resistir una cocción prolongada. |
| Corte y método | Los cortes con tejido conjuntivo se benefician de cocción larga y húmeda, no de tratarse como filetes magros. |
| Temperatura | El tamaño de corte modifica el tiempo, pero no reemplaza comprobar la temperatura segura de la carne. |

## Procedimiento

1. Identificar el tipo de pieza y el método previsto antes de cortar; mantener la carne refrigerada hasta su preparación.
2. Usar una tabla estable y cuchillo limpio, afilado y apto para la pieza.
3. Observar la dirección de las fibras de la carne cuando sea visible y orientar el cuchillo para cortarlas transversalmente.
4. Cortar tiras de grosor similar para salteados, medallones parejos para sellados o dados suficientemente grandes para estofados.
5. Retirar membranas duras cuando la preparación lo requiera, sin eliminar innecesariamente toda la grasa protectora.
6. Cocinar según el corte y comprobar la seguridad alimentaria; limpiar y desinfectar superficie y utensilios tras el contacto con carne cruda.

## Problemas frecuentes

| Problema | Causa | Ajuste |
|---|---|---|
| Tiras correosas | Corte paralelo a la fibra | Cortar transversalmente a las fibras |
| Piezas con puntos desiguales | Grosores muy diferentes | Uniformar el corte |
| Guiso de carne dura | Corte y método mal combinados | Seleccionar pieza apta para cocción prolongada |

## Seguridad y conservación

Separar cuchillos y tablas de carne cruda y alimentos listos para consumo. No lavar aves crudas. Para pollo, comprobar al menos 74 °C en la parte más gruesa; otras carnes y la carne picada tienen referencias distintas según producto.
