# Carnes

## Objetivo

El módulo **Carnes** reúne recetas y técnicas para cocinar proteínas animales con control de textura, sabor y seguridad alimentaria. La colección abarca pollo, ternera y cerdo, y diferencia plancha, horno, salteado, guiso y estofado.

## Seguridad transversal

- Evitar lavar el pollo crudo.
- Separar superficies y utensilios para ingredientes crudos y listos para consumir.
- Cocinar pollo hasta **74 °C en la parte más gruesa**, medidos con termómetro alimentario.
- No considerar el dorado exterior ni el color de los jugos como prueba suficiente de cocción.
- Refrigerar rápidamente las sobras y recalentar completamente.

Para piezas enteras de ternera y cerdo, consultar las temperaturas y reposos aplicables en [Sellar y cocinar filetes](../00_Bases/03_Tecnicas/sellar_y_cocinar_filetes.md); no aplicar automáticamente la referencia de pollo a todas las carnes.

## Ruta de aprendizaje

1. Leer [Cocinar pollo a la plancha](../00_Bases/03_Tecnicas/cocinar_pollo_a_la_plancha.md).
2. Preparar la [pechuga a la plancha](./pechuga_de_pollo_a_la_plancha.md) y practicar el uso del termómetro.
3. Comparar la cocción de [pollo al horno](./pollo_al_horno_con_verduras.md) y [pollo salteado](./pollo_salteado_con_jengibre_y_soja.md).
4. Preparar el [pollo guisado](./pollo_guisado_con_tomate.md) para trabajar el sofrito y la reducción de salsa.
5. Practicar [sellado y cocción de filetes](../00_Bases/03_Tecnicas/sellar_y_cocinar_filetes.md) con [ternera](./filetes_de_ternera_con_ajo.md) y [secreto de cerdo](./secreto_de_cerdo_a_la_plancha.md).
6. Comparar [ternera guisada](./ternera_guisada_con_verduras.md) y [lomo con mostaza](./lomo_de_cerdo_con_mostaza.md) para distinguir estofado prolongado de salsa corta.

## Criterios del módulo

- Diferenciar los cortes y sus tiempos de cocción.
- Tratar los tiempos como orientativos y verificar temperaturas seguras.
- Evitar contaminación cruzada.
- Documentar técnicas y recetas con referencias cruzadas.
- Incorporar otras carnes cuando aporten técnicas o perfiles propios.

## Evolución del módulo

Se ampliará con nuevos cortes, técnicas de estofado, asados y cocción lenta, con precauciones específicas para cada producto.
