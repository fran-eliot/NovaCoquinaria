    Modelo de Madurez del Conocimiento¶

    Proyecto: NovaCoquinaria Sistema: GASTRO – Sistema de Gestión del Conocimiento Culinario (SGCC)

    Objetivo¶

    Este documento define el modelo utilizado para evaluar la madurez del conocimiento dentro del Sistema de Gestión del Conocimiento Culinario (SGCC).

    Su finalidad consiste en disponer de un marco común para analizar la evolución de los distintos dominios de conocimiento, identificar oportunidades de mejora y orientar las decisiones estratégicas.

    La madurez no mide la cantidad de documentos, sino la calidad y consolidación del conocimiento.

    Alcance¶

    Este modelo permite evaluar:

    • dominios culinarios;
    • colecciones de conocimiento;
    • categorías documentales;
    • el SGCC en su conjunto.

    No evalúa documentos individuales.

    Filosofía¶

    La madurez representa el grado de consolidación alcanzado por un dominio de conocimiento.

    Un dominio maduro no es aquel que contiene más documentos, sino aquel cuyo conocimiento resulta:

    • completo;
    • reutilizable;
    • conectado;
    • mantenible;
    • útil.

    Principios¶

    La evaluación de la madurez se basa en los siguientes principios.

    • La calidad prevalece sobre la cantidad.
    • La reutilización prevalece sobre la duplicación.
    • La conectividad aumenta el valor del conocimiento.
    • La evolución debe ser progresiva.
    • La madurez nunca es definitiva.

    Modelo de madurez¶

    El SGCC adopta un modelo de seis niveles.

    Nivel 0 · No iniciado¶

    No existe conocimiento documentado.

    Nivel 1 · Inicial¶

    Existen documentos básicos.

    Todavía predominan lagunas importantes.

    Nivel 2 · Estructurado¶

    El dominio dispone de una organización coherente.

    Empiezan a aparecer relaciones reutilizables.

    Nivel 3 · Reutilizable¶

    El conocimiento se reutiliza de forma habitual.

    Las recetas se apoyan en documentos especializados.

    Nivel 4 · Consolidado¶

    El dominio presenta:

    • alta calidad;
    • buena cobertura;
    • elevada conectividad;
    • baja deuda de conocimiento.

    Nivel 5 · Referencia¶

    El dominio constituye un modelo para el resto del SGCC.

    Sirve como ejemplo de organización, reutilización y calidad.

    Dimensiones de evaluación¶

    La madurez se determina mediante varias dimensiones complementarias.

    Cobertura¶

    Existencia del conocimiento necesario para el dominio.

    Calidad¶

    Nivel editorial y estructural.

    Reutilización¶

    Frecuencia y amplitud de reutilización.

    Conectividad¶

    Integración con el Knowledge Graph.

    Deuda¶

    Cantidad e impacto de deuda de conocimiento pendiente.

    Evolución¶

    Capacidad del dominio para crecer sin perder coherencia.

    Interpretación¶

    La valoración de un dominio nunca dependerá de una única dimensión.

    Un dominio con mucha cobertura pero poca reutilización podrá presentar una madurez inferior a otro más pequeño pero mejor conectado.

    La evaluación será siempre global.

    Evaluación¶

    La evaluación combinará:

    Métricas automáticas¶

    • conectividad;
    • reutilización;
    • cobertura;
    • integridad estructural.

    Revisión editorial¶

    • claridad;
    • coherencia;
    • utilidad.

    Revisión arquitectónica¶

    • integración;
    • organización;
    • ausencia de duplicidades.

    Evolución¶

    La madurez constituye un indicador dinámico.

    Los dominios podrán:

    • avanzar;
    • mantenerse;
    • retroceder.

    Las regresiones permitirán detectar deterioro del conocimiento.

    Relación con otros modelos¶

    El modelo interactúa con:

    • Estrategia del conocimiento.
    • Modelo de calidad.
    • Deuda de conocimiento.
    • Colecciones.
    • Roadmap.

    Cada uno analiza una dimensión distinta del SGCC.

    Aplicaciones¶

    El modelo podrá utilizarse para:

    • priorización;
    • planificación;
    • dashboards;
    • métricas;
    • visualización;
    • informes históricos;
    • asistentes inteligentes.

    Gobernanza¶

    La evaluación de la madurez constituye un mecanismo de apoyo a la toma de decisiones.

    Nunca sustituye el juicio editorial.

    Conclusión¶

    La madurez representa el grado de consolidación del conocimiento dentro del SGCC.

    Su evaluación permite orientar la evolución del sistema, identificar áreas prioritarias de mejora y garantizar que el crecimiento del conocimiento se produzca de forma equilibrada, reutilizable y sostenible.
