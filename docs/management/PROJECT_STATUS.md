## Objetivo del proyecto

NovaCoquinaria tiene como objetivo construir una base de conocimiento culinario modular, reutilizable y mantenible.

El conocimiento se documenta una sola vez y se reutiliza mediante referencias entre recetas, técnicas, ingredientes, plantillas y tablas.
