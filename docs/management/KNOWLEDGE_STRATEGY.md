# Estrategia de Desarrollo del Conocimiento

> Principios y criterios que guían la evolución del conocimiento en NovaCoquinaria.

---

# Objetivo

Este documento define la estrategia utilizada para desarrollar el Sistema de Gestión del Conocimiento Culinario (SGCC).

No establece una lista de tareas ni un calendario.

Su finalidad es proporcionar criterios estables para decidir cómo debe crecer el conocimiento del proyecto.

---

# Principios estratégicos

La evolución del conocimiento seguirá, por orden de prioridad, los siguientes principios:

1. Coherencia arquitectónica.
2. Calidad documental.
3. Reutilización del conocimiento.
4. Conectividad del Knowledge Graph.
5. Cobertura equilibrada de los dominios culinarios.
6. Incorporación de nuevas recetas.

Siempre que exista conflicto entre dos criterios, prevalecerá el situado en una posición superior.

---

# Filosofía de crecimiento

NovaCoquinaria prioriza la construcción de conocimiento reutilizable frente a la incorporación de contenido aislado.

Siempre que sea posible:

* primero se documentarán bases y técnicas;
* después ingredientes y plantillas;
* finalmente recetas.

Cada receta deberá aportar valor al conjunto del conocimiento existente.

---

# Priorización

Antes de crear un nuevo documento se evaluará:

* ¿Existe ya conocimiento equivalente?
* ¿Puede reutilizarse una plantilla existente?
* ¿Debe ampliarse un documento actual en lugar de crear otro?
* ¿Reduce esta incorporación la deuda de conocimiento?
* ¿Incrementa la reutilización del SGCC?

---

# Dominios prioritarios

El crecimiento del proyecto se organizará por dominios culinarios.

En cada iteración se procurará consolidar un dominio antes de iniciar otro.

Dominios actualmente prioritarios:

1. Wok.
2. Currys.
3. Arroces.
4. Cocina mediterránea.

El orden podrá modificarse según las necesidades del proyecto.

---

# Uso del Knowledge Graph

El Knowledge Graph constituye una herramienta de apoyo para la toma de decisiones.

Se utilizará para:

* detectar documentos huérfanos;
* identificar conocimiento poco reutilizado;
* localizar dominios insuficientemente conectados;
* evaluar la evolución del repositorio.

Las métricas obtenidas no sustituyen la revisión editorial.

La estrategia deberá revisarse únicamente cuando cambie la filosofía de evolución del proyecto.

Las modificaciones menores del conocimiento no requerirán cambios en este documento.
