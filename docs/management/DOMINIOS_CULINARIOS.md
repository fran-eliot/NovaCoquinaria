# Dominios culinarios

## Fuente de información

Este documento ofrece una visión ejecutiva del estado de los dominios culinarios.

El detalle de ingredientes, técnicas, plantillas, recetas, relaciones y métricas será obtenido progresivamente mediante herramientas automáticas de auditoría del repositorio.

Por tanto, este documento no pretende sustituir al conocimiento almacenado en el SGCC, sino resumir su estado de evolución.

## ¿Qué es un dominio culinario?

En NovaCoquinaria, un dominio culinario es un conjunto cohesionado de conocimientos relacionados con una misma familia de elaboraciones, ingredientes, técnicas o patrones de cocina.

Un dominio se considera una unidad de evolución del conocimiento. Su objetivo no es acumular recetas, sino organizar y formalizar conocimiento reutilizable mediante ingredientes, técnicas, bases, plantillas, recetas de referencia, variantes y relaciones dentro del SGCC.

## Objetivo

Este documento mantiene el inventario de los dominios culinarios del Sistema de Gestión del Conocimiento Culinario (SGCC).

Cada dominio representa un conjunto cohesionado de conocimientos (ingredientes, técnicas, bases, plantillas y recetas) que evolucionan de forma conjunta hasta alcanzar un nivel de madurez suficiente.

No pretende ser un listado de recetas, sino una herramienta para planificar, medir y priorizar la expansión del conocimiento de NovaCoquinaria.

## Escala de madurez

| Nivel | Significado |
|--------|-------------|
| 🌱 Exploración | Conocimiento inicial. |
| 🌿 Estructurado | Existen documentos básicos y primeras relaciones. |
| 🌳 Consolidado | El dominio dispone de una estructura reutilizable y una cobertura amplia. |
| 🏛 Referencia SGCC | Dominio considerado modelo de calidad para el resto del sistema. |

---

## Criterios para considerar el dominio completo

Un dominio se considera suficientemente consolidado cuando permite generar nuevas recetas o variantes reutilizando conocimiento existente, sin necesidad de redefinir los conceptos fundamentales del dominio.

- Ingredientes principales documentados.
- Técnicas relacionadas documentadas.
- Plantilla consolidada.
- Al menos una receta canónica.
- Variantes principales modeladas.
- Relaciones SGCC completas.
- Al menos una implementación de referencia.
