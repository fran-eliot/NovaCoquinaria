# QUALITY

> **Proyecto:** NovaCoquinaria
> **Sistema:** GASTRO - Sistema de Gestión del Conocimiento Culinario (SGCC)

---

# Objetivo

Este documento define los criterios mínimos de calidad que debe cumplir cualquier contenido incorporado al proyecto.

Su finalidad es mantener la coherencia, facilitar el mantenimiento y asegurar que la base de conocimiento pueda evolucionar de forma sostenible.

---

# Principios de calidad

Todo documento debe cumplir estos principios:

* Tener una única responsabilidad.
* Aportar conocimiento útil.
* Evitar duplicidades.
* Favorecer la reutilización.
* Mantener un lenguaje claro y preciso.
* Integrarse de forma natural en la arquitectura del repositorio.

---

# Checklist de calidad

Antes de considerar un documento terminado, comprobar que:

## Contenido

* [ ] Aporta conocimiento nuevo o mejora uno existente.
* [ ] No duplica información ya documentada.
* [ ] Tiene una finalidad clara.
* [ ] Mantiene el nivel de detalle adecuado.

## Estructura

* [ ] Sigue la estructura definida para su tipo de documento.
* [ ] Utiliza los encabezados adecuados.
* [ ] Respeta la Guía de Estilo.
* [ ] Incluye Front Matter cuando corresponde.

## Integración

* [ ] Enlaza el conocimiento relacionado.
* [ ] Utiliza referencias relativas correctas.
* [ ] No deja enlaces rotos.
* [ ] Encaja dentro de la arquitectura del proyecto.

## Consistencia

* [ ] Mantiene la terminología oficial.
* [ ] Utiliza la nomenclatura establecida.
* [ ] Sigue la filosofía de NovaCoquinaria.
* [ ] Es comprensible tanto para personas como para futuras herramientas.

---

# Criterios de aceptación

Un documento puede considerarse listo cuando:

* cumple los principios del proyecto;
* supera el checklist anterior;
* no requiere modificaciones estructurales inmediatas;
* puede reutilizarse desde otros documentos.

---

# Mejora continua

La calidad no implica perfección.

Los documentos evolucionarán con el tiempo conforme aumente el conocimiento del sistema.

El objetivo es mejorar de forma incremental sin comprometer la estabilidad del repositorio.

---

# Regla de oro

Antes de dar un documento por finalizado, responder a esta pregunta:

> **¿Este documento hace que NovaCoquinaria sea un poco mejor que ayer?**

Si la respuesta es afirmativa, el documento está listo para formar parte de la base de conocimiento.
