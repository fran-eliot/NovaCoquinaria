# Architecture Decision Records

> Registro de las decisiones arquitectónicas de NovaCoquinaria.

## Objetivo

Los Architecture Decision Records documentan las decisiones relevantes que condicionan la arquitectura y evolución del SGCC.

Cada ADR conserva:

- el contexto de la decisión;
- la solución adoptada;
- sus consecuencias;
- las relaciones con otras decisiones.
