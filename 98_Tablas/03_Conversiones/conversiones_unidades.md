# Conversiones de Unidades

## Objetivo

Este documento recoge conversiones básicas de unidades utilizadas en cocina.

Sirve como referencia común para recetas, técnicas, tablas y plantillas del repositorio.

---

# Peso

| Unidad | Equivalencia |
| ------ | -----------: |
| 1 kg   |       1000 g |
| 1 g    |      1000 mg |
| 100 g  |       0,1 kg |
| 500 g  |       0,5 kg |
| 250 g  |      0,25 kg |

---

# Volumen

| Unidad | Equivalencia |
| ------ | -----------: |
| 1 l    |      1000 ml |
| 1 dl   |       100 ml |
| 1 cl   |        10 ml |
| 500 ml |        0,5 l |
| 250 ml |       0,25 l |

---

# Cucharas y cucharillas

| Medida             | Equivalencia aproximada |
| ------------------ | ----------------------: |
| 1 cucharada sopera |                   15 ml |
| 1 cucharadita      |                    5 ml |
| 1/2 cucharadita    |                  2,5 ml |
| 1/4 cucharadita    |                 1,25 ml |

# Reglas prácticas

* Para recetas del repositorio se priorizarán gramos, mililitros y grados Celsius.
* Las cucharadas y tazas se usarán solo como referencia aproximada.
* En repostería se evitarán medidas ambiguas y se priorizará siempre el peso.
* En cocina salada pueden admitirse medidas orientativas cuando el margen de error sea bajo.

---

# Errores frecuentes

## Confundir peso y volumen

No todos los ingredientes pesan igual aunque ocupen el mismo volumen.

Ejemplo:

* 1 cucharada de agua ≈ 15 g
* 1 cucharada de aceite ≈ 13-14 g
* 1 cucharada de harina ≈ 8-10 g

---

## Usar tazas sin estandarizar

Las tazas domésticas no siempre equivalen a 240 ml.

Para precisión, usar báscula o medidor.

---

## Medir ingredientes densos como líquidos

Miel, tahini, miso, tomate concentrado o mantequilla no deben tratarse siempre como líquidos aunque puedan medirse en cucharadas.

---

# Recomendación del repositorio

Formato preferido en recetas:

```text
200 g de arroz
500 ml de caldo
10 ml de salsa de soja
180 °C durante 25 min
```

Evitar:

```text
un vaso de arroz
un chorro de aceite
un poco de salsa
horno medio
```

Salvo que se explique claramente que la cantidad es flexible.
