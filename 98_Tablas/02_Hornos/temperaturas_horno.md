# Temperaturas de Horno

## Objetivo

Esta tabla resume las temperaturas habituales de utilización del horno doméstico.

Sirve como guía rápida para interpretar recetas y seleccionar la temperatura más adecuada según el tipo de elaboración.

---

# Equivalencias

| Temperatura | Uso habitual                                    |
| ----------: | ----------------------------------------------- |
|   80–100 °C | Mantener caliente, secado lento, confitados     |
|  110–130 °C | Cocción muy lenta                               |
|  140–160 °C | Asados lentos, verduras, carnes melosas         |
|  170–180 °C | Temperatura estándar para la mayoría de recetas |
|  190–200 °C | Gratinados suaves, pizzas, verduras asadas      |
|  210–220 °C | Dorado intenso, panes, hojaldres                |
|  230–250 °C | Pizza de estilo italiano, acabado rápido        |

# Tipos de calor

| Modo                 | Cuándo utilizarlo                                                                  |
| -------------------- | ---------------------------------------------------------------------------------- |
| Calor arriba y abajo | Opción por defecto para la mayoría de recetas                                      |
| Aire o convección    | Cocción uniforme y más rápida; suele requerir reducir la temperatura unos 15–20 °C |
| Grill                | Gratinar o dorar la superficie                                                     |
| Grill con ventilador | Dorado rápido con mayor uniformidad                                                |

---

# Recomendaciones

* Precalentar el horno salvo que la receta indique lo contrario.
* Utilizar la posición central como referencia general.
* Ajustar el tiempo si se utiliza convección.
* Evitar abrir la puerta durante los primeros minutos de cocción, especialmente en repostería.

---

# Errores frecuentes

* Introducir los alimentos sin precalentar el horno.
* No adaptar la temperatura al usar aire.
* Confiar únicamente en el tiempo y no observar el grado de cocción.
* Colocar la bandeja demasiado cerca de las resistencias.
