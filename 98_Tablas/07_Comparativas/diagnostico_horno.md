# Diagnóstico de cocción al horno

## Objetivo

Identificar causas de problemas frecuentes en asados, bandejas, gratinados y papillotes, y proponer correcciones.

## Diagnóstico general

| Síntoma | Causa probable | Acción |
|---|---|---|
| Exterior quemado e interior crudo | Temperatura excesiva o pieza gruesa | Reducir temperatura y prolongar cocción |
| Poco dorado | Superficie húmeda o bandeja llena | Secar y espaciar |
| Verduras blandas | Exceso de vapor | Repartir en bandejas |
| Fondo seco y quemado | Falta de líquido en asado tapado | Añadir líquido caliente |
| Carne dura | Tiempo insuficiente para el corte | Prolongar cocción controlada |
| Carne seca | Sobrecalentamiento o cocción excesiva | Medir temperatura y ajustar |
| Gratinado quemado | Exceso de tiempo bajo grill | Vigilar continuamente |
| Pescado seco | Horneado excesivo | Reducir tiempo según grosor |
| Papillote con verduras duras | Corte demasiado grueso | Cortar fino o precocer |
| Patatas duras | Gajos gruesos o cocción insuficiente | Precocer o prolongar |

## Selección del método

| Objetivo | Método recomendado | Precaución |
|---|---|---|
| Costillas tiernas | Asado lento tapado y dorado final | Comprobar seguridad y terneza |
| Verduras doradas | Asado seco en bandeja amplia | Evitar amontonar |
| Pescado jugoso | Papillote o asado breve | Vigilar grosor |
| Queso dorado | Gratinado final | No alejarse del horno |
| Plato completo | Bandeja con tiempos coordinados | Escalonar ingredientes |

## Control de seguridad

El color no sustituye a la medición de temperatura interna. Para pollo, utilizar **74 °C**; para pescado, **63 °C** como referencia. En piezas enteras de cerdo, **63 °C y 3 minutos de reposo** es el mínimo de seguridad, aunque algunos cortes requieren mayor cocción para lograr terneza. Evitar contaminación cruzada.
