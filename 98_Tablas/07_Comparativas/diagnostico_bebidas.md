# Proporciones y diagnóstico de bebidas

## Objetivo
Ofrecer referencias de formulación y corrección para bebidas calientes, frías, infusionadas y trituradas.

## Proporciones orientativas
| Bebida | Referencia inicial | Variable principal |
|---|---|---|
| Café de filtro | 60 g café / 1 l agua | Molienda y extracción |
| Café con leche | 100 ml café / 150 ml leche | Intensidad |
| Té negro | 2–3 g / 250 ml agua | Tiempo y temperatura |
| Limonada | 150 ml limón / 850 ml agua | Acidez y azúcar |
| Chocolate caliente | 20 g cacao / 250 ml leche | Cuerpo y dulzor |
| Batido de fruta | 110 g plátano / 175 ml leche | Madurez y espesor |

## Diagnóstico
| Problema | Causa probable | Acción |
|---|---|---|
| Café amargo | Extracción excesiva | Revisar molienda y tiempo |
| Café débil | Baja dosis o subextracción | Ajustar proporción |
| Té astringente | Infusión larga | Colar antes |
| Chocolate con grumos | Cacao mal dispersado | Mezclar con líquido frío antes de calentar |
| Bebida cítrica muy ácida | Zumo excesivo | Diluir gradualmente |
| Batido demasiado espeso | Poco líquido | Añadir líquido frío |
| Bebida fría aguada | Exceso de hielo | Refrigerar antes |

## Seguridad y alérgenos
La cafeína varía con tipo y preparación. Revisar leche, soja y frutos secos de bebidas vegetales. Enfriar y refrigerar pronto las bebidas perecederas. Las cantidades son puntos de partida, no estándares universales.
