# Seguridad Alimentaria

## Objetivo

Este documento recoge las normas básicas de seguridad alimentaria para minimizar el riesgo de enfermedades transmitidas por los alimentos.

Debe considerarse una referencia general para todas las recetas y técnicas del repositorio.

---

# Zona de peligro

Las bacterias se multiplican con mayor rapidez entre:

|      Temperatura |
| ---------------: |
| **5 °C – 60 °C** |

Reducir al mínimo el tiempo que los alimentos permanecen en este intervalo.

---

# Temperaturas recomendadas

| Situación                 | Temperatura |
| ------------------------- | ----------: |
| Refrigerador              |      ≤ 4 °C |
| Congelador                |    ≤ -18 °C |
| Recalentado               |     ≥ 75 °C |
| Mantenimiento en caliente |     ≥ 60 °C |

---

# Higiene personal

Antes de cocinar:

* Lavarse las manos con agua y jabón.
* Recoger el cabello largo.
* Utilizar utensilios limpios.
* Evitar cocinar estando enfermo.

---

# Contaminación cruzada

Evitar el contacto entre:

* carnes crudas y alimentos listos para consumir;
* pescado crudo y verduras ya lavadas;
* utensilios utilizados con alimentos crudos y cocinados.

Recomendaciones:

* utilizar tablas de cortar diferentes o lavarlas entre usos;
* cambiar cuchillos cuando sea necesario;
* lavar las manos tras manipular alimentos crudos.

---

# Descongelación segura

Métodos recomendados:

| Método               | Recomendación                   |
| -------------------- | ------------------------------- |
| Refrigerador         | ⭐⭐⭐ Recomendado                 |
| Microondas           | ⭐⭐☆ Consumir inmediatamente     |
| Cocción directa      | ⭐⭐⭐ Cuando la receta lo permita |
| Temperatura ambiente | ❌ No recomendado                |

---

# Cocción segura

Especial atención a:

| Producto     | Recomendación                                                  |
| ------------ | -------------------------------------------------------------- |
| Pollo        | Sin zonas rosadas                                              |
| Carne picada | Bien cocinada                                                  |
| Cerdo        | Cocinar completamente salvo piezas específicas                 |
| Pescado      | Carne opaca y fácilmente separable                             |
| Huevos       | Evitar preparaciones con huevo crudo si hay personas de riesgo |

---

# Conservación

* Refrigerar cuanto antes.
* No superar los tiempos recomendados.
* Mantener la cadena de frío.
* Etiquetar los alimentos preparados.

Consultar también:

* `98_Tablas/04_Conservacion/conservacion_congelacion.md`

---

# Limpieza

Después de cocinar:

* limpiar superficies;
* lavar utensilios;
* secar correctamente;
* sustituir bayetas deterioradas con frecuencia.

---

# Señales de alerta

Desechar el alimento si presenta:

* olor anormal;
* moho;
* envase hinchado;
* color extraño;
* textura viscosa.

En caso de duda:

> **No consumir.**

---

# Alimentos especialmente sensibles

* Carne picada.
* Pollo.
* Pescado fresco.
* Marisco.
* Arroz cocido.
* Platos con huevo.
* Lácteos frescos.

---

# Buenas prácticas

* Planificar antes de cocinar.
* Mantener la cocina ordenada.
* Utilizar recipientes adecuados.
* Etiquetar las preparaciones.
* Consumir primero los alimentos más antiguos (FIFO: *First In, First Out*).

---

# Errores frecuentes

* Descongelar sobre la encimera.
* Guardar alimentos varias horas a temperatura ambiente.
* Recalentar repetidamente la misma preparación.
* Utilizar la misma tabla para carne y verduras sin limpiarla.
* Confiar únicamente en el aspecto visual del alimento.
