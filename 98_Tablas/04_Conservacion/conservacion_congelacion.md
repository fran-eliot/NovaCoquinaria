# Conservación, Congelación y Recalentado

## Objetivo

Este documento resume las recomendaciones generales para conservar alimentos cocinados y materias primas de forma segura.

Los tiempos son orientativos y presuponen una correcta higiene y una refrigeración continua a **≤ 4 °C**.

---

# Conservación en refrigeración

| Alimento           | Tiempo recomendado |
| ------------------ | -----------------: |
| Arroces cocidos    |           2–3 días |
| Pasta cocida       |           3–4 días |
| Legumbres cocidas  |           3–4 días |
| Verduras cocinadas |           3–4 días |
| Carne cocinada     |           3–4 días |
| Pollo cocinado     |             3 días |
| Pescado cocinado   |             2 días |
| Marisco cocinado   |           1–2 días |
| Sopas y cremas     |           3–4 días |
| Salsas caseras     |           3–5 días |

# Alimentos que congelan peor

* Patata cocida (puede volverse harinosa).
* Lechuga.
* Pepino.
* Mayonesa.
* Natas montadas.
* Huevos cocidos enteros.

---

# Descongelación

Métodos recomendados:

| Método               | Recomendación                        |
| -------------------- | ------------------------------------ |
| Refrigerador         | ⭐⭐⭐ Recomendado                      |
| Microondas           | ⭐⭐☆ Consumir inmediatamente          |

# Recalentado

## Regla general

Recalentar hasta que el alimento alcance aproximadamente **75 °C en su interior**.

---

## Métodos

| Método     | Observaciones                     |
| ---------- | --------------------------------- |
| Microondas | Remover a mitad del proceso       |
| Sartén     | Ideal para arroces y salteados    |
| Horno      | Bueno para carnes y gratinados    |
| Vapor      | Excelente para verduras y pescado |

---

# Enfriado de alimentos

Después de cocinar:

* No dejar más de **2 horas** a temperatura ambiente.
* Dividir grandes cantidades en recipientes pequeños.
* Refrigerar cuando haya perdido el calor intenso.

---

# Reglas prácticas

* Etiquetar recipientes con la fecha.
* Congelar por raciones.
* Utilizar recipientes herméticos.
* Evitar abrir y cerrar repetidamente los envases.

---

# No volver a congelar

No volver a congelar un alimento descongelado salvo que:

* se cocine completamente antes de volver a congelarlo.

---

# Señales de deterioro

Desechar el alimento si presenta:

* olor desagradable;
* moho;
* fermentación;
* envase hinchado;
* textura anómala.

En caso de duda:

> **Desechar siempre el alimento.**

---

# Batch Cooking

Para preparar varias raciones:

* Cocinar completamente.
* Enfriar rápidamente.
* Dividir en porciones individuales.
* Etiquetar con fecha.
* Congelar si no se consumirán en los siguientes tres días.

---

# Errores frecuentes

* Guardar alimentos aún muy calientes en el frigorífico.
* Congelar recipientes demasiado grandes.
* Descongelar sobre la encimera.
* Recalentar varias veces la misma preparación.
* No etiquetar las fechas.
