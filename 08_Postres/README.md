# Postres

## Objetivo
Organizar elaboraciones dulces domésticas por estructura, técnica y punto de cocción, diferenciando pasteles húmedos, bizcochos aireados y postres de cuchara.

## Seguridad y alérgenos
- Revisar presencia de huevo, leche, trigo/gluten y frutos secos según receta.
- Evitar probar masas con harina o huevo crudos.
- Refrigerar rápidamente elaboraciones húmedas y cremas perecederas.
- En preparaciones con arroz cocido, evitar periodos prolongados a temperatura ambiente.

## Ruta de aprendizaje
1. Estudiar [horneado de bizcochos y pasteles](../00_Bases/03_Tecnicas/hornear_bizcochos.md).
2. Comparar [pastel de manzana](./pastel_de_manzana.md) y [bizcocho de yogur](./bizcocho_de_yogur.md) para distinguir masas húmedas y aireadas.
3. Preparar [natillas](./natillas_caseras.md) para practicar espesado.
4. Preparar [arroz con leche](./arroz_con_leche.md) para practicar cocción suave y control de textura.
